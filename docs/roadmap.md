# Roadmap

## Phase 1: Foundation

- CMake project layout
- core math types
- `StateVector`
- `DynamicalSystem`
- Euler and RK4 integrators
- single pendulum model
- basic SFML renderer

## Phase 2: Interactive Double Pendulum

- double pendulum equations
- pause/reset/step controls
- trajectory buffers
- mouse selection and dragging
- impulse application

## Phase 3: Multi-World Sandbox

- multiple simultaneous simulation worlds
- viewport splitting
- per-world parameters
- presets and reset states

## Phase 4: Chained Pendulums

- N-link state layout
- chain pendulum model
- model validation
- performance profiling

## Phase 5: Chaos Lab

- energy graphs
- divergence visualization
- Lyapunov experiments
- simulation recording/replay
- data export
